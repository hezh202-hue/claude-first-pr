# 群星联机助手

给《群星》(Stellaris) 多人联机用的一套小工具：在一台自己的 VPS 上跑 SoftEther，
把分散在各地的朋友接进同一个虚拟局域网，并提供一个图形界面来一键连接和查看状态。

## 快速上手

1. 双击 `群星联机助手.exe`（会申请管理员权限，用于创建虚拟网卡和放行防火墙）
2. 第一页填房主给的连接信息 → 点【一键连接】
3. 第二页可以看谁在线、延迟多少

## 三个页签

| 页签 | 作用 |
|---|---|
| 一键连接 | 自动装客户端 → 建虚拟网卡 → 拨号 → 等 DHCP → 放行防火墙，六步全自动 |
| 状态监视 | 连接状态、延迟、局域网成员、游戏进程，6 秒自动刷新，可一键复制诊断报告 |
| 部署服务器 | 房主用。生成一条 base64 单行命令，粘到服务器上即可完成整套部署 |

## 技术要点

- **单文件、零依赖**：C# + WinForms，编译目标 .NET Framework 4.8（Win10/11 自带），
  产物 43 KB，拿到就能跑，不需要安装运行时。
- **成员发现同时用 ping 和 ARP**：Windows 默认拦 ICMP，只靠 ping 会漏掉在线的人；
  ARP 是二层协议，网卡自己就回应，拦不掉。两者结合才不漏报。
- **DHCP 不下发默认网关**：只发 IP。否则所有人的上网流量都要绕道服务器，又慢又费带宽。
  虚拟局域网只承载游戏流量。
- **防火墙只对 `192.168.30.0/24` 开放**：不是整体放行，不影响平时的上网安全。
- **部署脚本批量建账号**：逐个建会因为密集开管理连接触发 SoftEther 防护而失败。

## 编译

```
csc /target:winexe /codepage:65001 /optimize+ ^
    /reference:System.dll,System.Drawing.dll,System.Windows.Forms.dll,System.ServiceProcess.dll,System.Core.dll ^
    /out:群星联机助手.exe StellarisTool.cs
```

`csc.exe` 在 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\` 下，Windows 自带，不用装 SDK。

## 一个重要前提

**《群星》没有真正的局域网模式。** 它的联机基于 Steam 网络，主机开房必须先从
Steam 匹配服务器拿到一个 ServerID。虚拟局域网解决的是 NAT 穿透和线路质量，
解决不了"连不上匹配服务器"。如果卡在等待 ServerID，那是 Steam 侧的连通性问题。
