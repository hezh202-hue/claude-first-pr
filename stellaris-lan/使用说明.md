# 群星联机助手 · 使用说明

## 文件都是干嘛的

| 文件 | 谁用 | 说明 |
|---|---|---|
| **群星联机助手.bat** | 所有人 | **双击这个**。会自动申请管理员权限并打开图形界面 |
| StellarisLAN.ps1 | — | 程序本体，别单独运行，让上面那个 bat 来调它 |
| install_softether.sh | 房主（备用） | 不想用图形界面时，手动上传到服务器执行的脚本 |
| setup_generated.sh | — | 程序自动生成的，出问题时给我看这个 |

---

## 这套东西的原理（一句话版）

群星**没有独立服务端**，联机永远是「谁开房谁当主机」。所以这台香港服务器不是拿来跑游戏的，
它是一间**公共会议室**：大家都连进去之后，Windows 会以为你们坐在同一个网吧的局域网里，
游戏的 LAN 大厅就能直接互相看见，不用做端口映射。

## 房主：只做一次的三步

### 第 0 步 · 先改密码（重要）
你的 root 密码在截图里露出过。椰子云控制台 → 实例 → 登录信息 → **重置密码**。

### 第 1 步 · 放行端口
椰子云控制台 → 实例详情 → **安全组** → 添加入站规则：

- TCP **443** （玩家连接用，伪装成 HTTPS，什么网络环境都不会被拦）
- TCP **992** （备用）
- TCP **5555** （以后你想用图形管理器远程管理时用）

> 安全组就像小区大门的保安。你在楼里开了门没用，保安不放人进来照样白搭 —— 这步最常被忘。

### 第 2 步 · 用工具部署
双击 **群星联机助手.bat** → 切到「部署服务器（房主用）」页：

1. 填服务器 IP、管理密码、玩家密码、账号个数
   （密码只用字母数字，别带引号空格 —— 程序会拦住你，但还是提一句）
2. 点 **【生成部署命令并复制】** —— 整个安装脚本被压成一行，已在剪贴板里
3. 点 **【打开SSH窗口】** → 输入 root 密码（**输入时屏幕不显示字符，这是正常的**）
4. 在黑窗口里**点鼠标右键 = 粘贴**，然后回车
5. 等 1~3 分钟，看到「部署完成」就好了
6. 回到工具点 **【生成给朋友的信息】**，直接粘到群里

## 所有玩家（包括房主）：连接

双击 **群星联机助手.bat** → 第一页填房主给的 4 条信息 → 点 **【一键连接】**。

程序会自动做完这些事：

1. 检查有没有装 SoftEther 客户端，没有就下载（这一步会弹安装程序，一路 Next）
2. 建虚拟网卡 —— 相当于给电脑插一块看不见的网卡
3. 写配置、拨号
4. 等服务器分配 `192.168.30.x` 的局域网地址
5. **自动放行 Windows 防火墙** ← 这步是关键，见下面

看到绿色的「全部就绪」和自己的局域网地址，就可以开游戏了。
下次再玩，打开工具直接点【一键连接】即可，信息都记住了。

### 为什么必须要管理员权限

Windows 遇到新冒出来的网卡，会当成「公用网络」，默认把所有外来连接全拦掉。
结果就是经典现象：**大家 VPN 都显示已连接，但游戏里就是看不到彼此的房间。**

程序会自动把这块虚拟网卡改成「专用网络」，并只放行来自 `192.168.30.0/24` 的连接
—— 也就是只对你们这几个人开放，不影响平时上网的安全性。
但改防火墙需要管理员权限，所以请务必用 **.bat** 打开（它会弹 UAC 让你点「是」）。

## 开黑

1. 所有人先在工具里点【一键连接】
2. 进群星 → **多人游戏** → **局域网 / LAN** 标签页
3. 房主点「主持游戏」，其他人应该能直接在列表里看到房间

### 三条铁律（不满足就是连不上，跟服务器无关）

1. **所有人游戏版本必须完全一致** —— 有一个人偷偷更新了就全崩
2. **所有人 MOD 必须完全一致**，包括启用顺序 —— 校验和不同直接拒绝连接
3. **房主选单核性能最强的那位** —— 群星后期几百个国家算 AI，吃的是 CPU 单核，不是显卡

## 出问题怎么办

**连接失败，提示连不上服务器**
→ 90% 是安全组没放行 443。回椰子云控制台检查。

**连上了，但游戏里看不到房间**
→ 99% 是防火墙。确认工具是用 .bat 打开的（标题栏会有「管理员」字样），
　 日志里第 6 步应该显示绿色的「已允许来自 192.168.30.0/24 的连接 ✓」。

**下载客户端失败**
→ 国内直连 GitHub 经常不稳。点【手动下载客户端】按钮，浏览器打开后找
　 `softether-vpnclient-...-windows-x86_x64-intel.exe` 下载，安装时选 **Client**（别选成 Server），
　 装完回来再点【一键连接】。

**连上 VPN 后上网变慢了？**
→ 不会。部署脚本特意没有下发默认网关，你的上网流量不会绕道香港，只有游戏的局域网流量走这条通道。

**想加人**
→ 在工具里把「账号个数」调大，重新生成命令再跑一遍即可（重复执行是安全的）。

**双击 bat 一闪就没了**
→ 说明 PowerShell 启动失败。把 setup_generated.sh 和报错截图发我。
